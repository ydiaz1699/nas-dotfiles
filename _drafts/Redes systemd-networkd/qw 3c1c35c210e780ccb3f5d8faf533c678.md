# 📘 Guía Definitiva: Debian 12 + systemd-networkd + Docker Compose + AdGuard (macvlan)

*Diseñada para evitar configuraciones duplicadas, pérdida de SSH y fallos en macvlan.*

> 🔒 **Antes de empezar**: Esta guía asume que tienes acceso por consola física, KVM o SSH. Si pierdes conexión, reinicia el servidor: `systemd-networkd` leerá los archivos al iniciar.
> 

---

## 📋 Mapa de Red (No modificar sin cambiar todos los archivos)

| Componente | IP | Función |
| --- | --- | --- |
| Router | `192.168.0.1` | Gateway |
| Host (Debian) | `192.168.0.200/24` | Servidor principal |
| Host Shim | `192.168.0.250/32` | Puente host ↔ macvlan |
| AdGuard | `192.168.0.201` | Contenedor DNS |
| Interfaz física | `eno1` | Confirmada en tu sistema |

## 🧹 FASE 0: Limpieza de estado previo (CRÍTICO)

*Evita el problema de IPs duplicadas (`.200` + `.14`)*

```bash
# 1. Desactivar definitivamente ifupdown
systemctl disable --now networking
systemctl mask networking

# 2. Eliminar configuración antigua de interfaces
rm -f /etc/network/interfaces
rm -rf /etc/network/interfaces.d/

# 3. Eliminar IP DHCP residual (NO uses flush, perderías SSH)
ip addr del 192.168.0.14/24 dev eno1 2>/dev/null || true

# 4. Verificar que solo queda la estática
ip -br addr show eno1
```

✅ **Checkpoint**: Debe mostrar solo `eno1 UP 192.168.0.200/24`

---

## 🌐 FASE 1: systemd-networkd sin sorpresas

### 1.1 Crear archivo principal

```bash
cat > /etc/systemd/network/10-eno1.network << 'EOF'
[Match]
Name=eno1

[Network]
Address=192.168.0.200/24
Gateway=192.168.0.1
DNS=1.1.1.1
DNS=8.8.8.8
DHCP=no
MACVLAN=macvlan-shim
ConfigureWithoutCarrier=yes
EOF
```

### 1.2 Activar y aplicar

```bash
systemctl enable --now systemd-networkd
systemctl restart systemd-networkd
sleep 3
networkctl status eno1
```

✅ **Checkpoint**: `State: routable (configured)` y solo una IPv4 listada.

## 🔗 FASE 2: Macvlan Shim (Comunicación Host ↔ Contenedor)

*Sin este paso, el host NO puede alcanzar `192.168.0.201`*

### 2.1 Definir interfaz virtual

```bash
cat > /etc/systemd/network/20-macvlan-shim.netdev << 'EOF'
[NetDev]
Name=macvlan-shim
Kind=macvlan

[MACVLAN]
Mode=bridge
EOF
```

### 2.2 Configurar IP y ruta

```bash
cat > /etc/systemd/network/20-macvlan-shim.network << 'EOF'
[Match]
Name=macvlan-shim

[Network]
Address=192.168.0.250/32

[Route]
Destination=192.168.0.201/32
Scope=link
EOF
```

### 2.3 Aplicar y verificar

```bash
systemctl restart systemd-networkd
sleep 2
ip -br addr show macvlan-shim
ip route | grep 192.168.0.201
```

✅ **Checkpoint**: `macvlan-shim` con `192.168.0.250/32` y ruta `192.168.0.201 via dev macvlan-shim`

## 🐳 FASE 3: Docker + Docker Compose

### 3.1 Instalación oficial (Debian 12)

```bash
apt update && apt install -y ca-certificates curl gnupg
install -m 0755 -d /etc/apt/keyrings
curl -fsSL <https://download.docker.com/linux/debian/gpg> | gpg --dearmor -o /etc/apt/keyrings/docker.gpg
chmod a+r /etc/apt/keyrings/docker.gpg

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] <https://download.docker.com/linux/debian> bookworm stable" > /etc/apt/sources.list.d/docker.list

apt update && apt install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

### 3.2 Verificar instalación

```bash
docker run --rm hello-world
docker compose version
```

✅ **Checkpoint**: `Hello from Docker!` y versión de compose `v2.x.x`

> 📌 `docker0` aparecerá como `DOWN`. Es normal. Solo se activa con redes bridge internas.

## 🛡️ FASE 4: Despliegue de AdGuard Home

### 4.1 Estructura de carpetas

```bash
mkdir -p /docker/adguard/{work,conf}
```

### 4.2 Archivo `compose.yaml`

```bash
cat > /docker/adguard/compose.yaml << 'EOF'
services:
  adguard:
    container_name: adguard
    image: adguard/adguardhome:latest
    cap_add:
      - NET_ADMIN
    networks:
      macvlan_NET:
        ipv4_address: 192.168.0.201
    volumes:
      - /docker/adguard/work:/opt/adguardhome/work
      - /docker/adguard/conf:/opt/adguardhome/conf
    restart: unless-stopped

networks:
  macvlan_NET:
    driver: macvlan
    driver_opts:
      parent: eno1
    ipam:
      config:
        - subnet: 192.168.0.0/24
          gateway: 192.168.0.1
EOF
```

### 4.3 Desplegar

```bash
cd /docker/adguard
docker compose up -d
docker compose ps
```

✅ **Checkpoint**: Estado `Up` y puerto `3000` disponible en `192.168.0.201`

## 🆘 Troubleshooting Rápido

| Síntoma | Causa más probable | Solución |
| --- | --- | --- |
| `eno1` muestra 2 IPs | `DHCP=no` falta o ifupdown activo | Ver FASE 0.1 y 1.1 |
| Host no ping a `.201` | Shim sin ruta o `MACVLAN=` falta en `10-eno1.network` | Verificar FASE 2.2 y 1.1 |
| AdGuard no arranca | IP ya usada en red o `parent:` incorrecto | `docker compose logs adguard`, verificar `ip a` |
| Pérdida de red tras reinicio | Falta `ConfigureWithoutCarrier=yes` | Agregar a `10-eno1.network` y reiniciar |
| DNS no resuelve | `resolv.conf` sobreescrito | `ln -sf /run/systemd/resolve/stub-resolv.conf /etc/resolv.conf` |

---

## 📌 Reglas de Oro para Evitar Errores

1. **Nunca edites red sin `DHCP=no`** si quieres IP estática con systemd-networkd.
2. **Siempre agrega `MACVLAN=shim`** en el archivo de la interfaz física.
3. **Verifica con `networkctl status`** antes de tocar Docker.
4. **Usa `ip -br`** para lectura limpia. Evita `ip a` largo en producción.
5. **Guarda los 4 archivos de red** en `/root/backup-networkd/` antes de modificarlos.

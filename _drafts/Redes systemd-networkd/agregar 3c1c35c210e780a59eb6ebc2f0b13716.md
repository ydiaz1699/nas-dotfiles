## Solución confirmada

El problema es simple: **`systemd-networkd` no está habilitado para arrancar automáticamente** al encender el servidor.

Ejecuta este comando para que nunca vuelva a pasar:

```bash
systemctl enable systemd-networkd
```

Con `start` solo lo enciendes una vez. Con `enable` lo activas para que arranque solo en cada boot.

Verifica que quedó habilitado:

```bash
systemctl is-enabled systemd-networkd
# Debe responder: enabled
```

Ahora sí puedes apagar y encender el servidor con tranquilidad.
